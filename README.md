## About Me

I'm a software engineer working across **AI, full-stack systems, cybersecurity, robotics, and low-level computing**.

I like projects where software has to do more than render another dashboard — language models, autonomous systems, compilers, security tooling, computer vision, embedded hardware, and infrastructure.

- Building AI products and intelligent software systems
- Working with **LLMs, agents, RAG, computer vision and ML**
- Developing production applications with **Next.js, React, Node.js and Python**
- Exploring **compilers, operating systems, assembly and low-level computing**
- Building robotics and embedded systems using **ROS, ESP32, Arduino and Raspberry Pi**
- Practicing offensive and defensive cybersecurity through **CTFs and security research**

- Built my own **programming language** and **language model**
